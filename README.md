# 机器学习学习笔记（sk_learning）

基于 scikit-learn 的机器学习入门学习，从决策树到模型评估，一课一个文件，每个文件均可独立运行。

## 运行环境

- Python 3（建议使用 conda 环境 `skl_env`）
- 依赖：`scikit-learn`、`numpy`

运行方式（示例）：

```powershell
conda activate skl_env
python "第八课_逻辑回归_乳腺癌.py"
```

## 课程目录

### 第三课：决策树 —— 鸢尾花分类

第一个机器学习模型。用**决策树**对鸢尾花按花瓣、花萼特征分类，用 `train_test_split` 划分训练集/测试集，评估准确率。

### 第七课：线性回归 —— 糖尿病指标预测

用**线性回归**根据 10 个生理指标预测糖尿病病情定量值，输出 MSE 与 R²。

### 第八课：逻辑回归 —— 乳腺癌分类

用**逻辑回归**（线性回归 + sigmoid 映射成 0~1 概率）对乳腺癌肿块做二分类，在测试集上达到 97.66% 准确率，并展示每个样本的预测置信度。

### 第九课：过拟合与欠拟合

用不同 `max_depth` 的决策树对比训练集/测试集准确率，直观演示过拟合：树越深训练集逼近 100%，测试集反而下滑。

### 第十课：防止过拟合 —— 验证集

把数据切成训练集 / 验证集 / 测试集三份，用**验证集**挑选 `max_depth`，最后才用锁起来的测试集做一次验收。

### 第十一课：交叉验证

用 `cross_val_score` 做 5 折交叉验证，多考几次取平均，解决"只切一次验证集"靠运气的问题，挑出稳定的最佳参数。

### 第十二课：GridSearchCV 调参

用 `GridSearchCV` 自动穷举 `max_depth` × `min_samples_leaf` 共 33 种组合、每种跑 5 折交叉验证，替掉手写双重循环，找到最优参数组合并测试集验收。

### 第十三课：评估分类 —— 混淆矩阵与 F1

用**混淆矩阵**（TN/FP/FN/TP）、**精确率、召回率、F1** 评估分类模型，并用一份 98% 正常 + 2% 异常的数据演示"准确率会骗人"——少数类场景下必须看召回率与精确率。

### 第十四课：ROC 曲线与 AUC

用 **ROC 曲线**（真正率 TPR vs 假正率 FPR）和 **AUC** 综合衡量模型在**所有阈值**下的排序能力，摆脱"只盯一个准确率"的局限。

### 第十五课：PR 曲线与失衡数据评估

在正负样本**极度不平衡**时，**PR 曲线与 AP** 比 ROC 更能反映模型对少数类的识别能力，并演示调整阈值时精确率与召回率的此消彼长。

### 第十六课：KNN 近邻

手算**欧氏距离**理解"近邻投票"；演示 `k` 取值与过拟合/欠拟合的对应关系，并说明距离类模型为什么必须先做**特征归一化**。

### 第十七课：SVM 支持向量机

讲透 **超平面 / 间隔 / 支持向量** 三个核心概念，用可视化把决策边界和最宽间隔画出来；对比 `C` 参数大小以及归一化前后对边界的影响。

### 第十八课：SVM 核函数

解决"线性不可分"：用**核函数**升维，配合 3D 图直观展示"升维后用平面切开"的原理，并对比 `linear` / `rbf` 核与 `gamma` 参数对应的欠拟合、最优、过拟合三档表现。

### 第十九课：SVM 多分类

SVM 天生只能二分类，本课讲解把它拆成多分类的两种套路——**OvR 一对多（公投）** 与 **OvO 一对一（擂台赛）**，手写实现并与 sklearn 封装结果逐一对照。

## 学习主线

```
决策树 → 线性回归 → 逻辑回归
→ 过拟合/欠拟合 → 验证集 → 交叉验证 → GridSearchCV
→ 分类评估（混淆矩阵 / 精确率 / 召回率 / F1）
→ ROC / AUC → PR / AP（失衡数据）
→ KNN 近邻
→ SVM（间隔 → 核函数 → 多分类）
```

之后会继续补充：随机森林、聚类等更多模型。
